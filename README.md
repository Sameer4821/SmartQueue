## Smart Queue Management
Smart Queue is a real-time digital queue management system designed to eliminate long waiting lines in hospitals and clinics.
It enables patients to digitally join queues, track their live position, and receive notifications — while allowing hospital staff to efficiently manage patient flow through a centralized dashboard.
This system replaces manual token systems with a scalable, secure, and intelligent backend-driven workflow.

## Problem Statement
Traditional hospital queue systems suffer from:
Manual token handling
No real-time updates
Long and unpredictable waiting times
Overcrowding
Poor patient experience
Smart Queue solves this using real-time queue tracking, OTP-based authentication, and structured backend processing.

##  System Workflow
Patient logs in using mobile number
OTP is sent via Twilio
OTP is verified
Patient joins digital queue
Staff updates queue status
Patients receive real-time updates
